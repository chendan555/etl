# Issue #6: 前端进度显示

## Parent

[PRD: 批量执行进度显示](../PRD.md)

## What to build

实现前端进度显示功能，将接收到的 WebSocket 进度消息更新到 UI 组件。包括进度条更新、统计信息刷新、批次详情表格更新。

核心功能：
- 更新进度条百分比和动画
- 更新统计区域：成功数、失败数、已用时间、预计剩余时间、总行数
- 更新批次详情表格，新增完成的批次行
- 标记成功/失败状态（绿色/红色）
- 计算并显示执行速度（批次/秒）
- 执行完成后显示"执行完成"提示

## Acceptance criteria

- [ ] 接收 WebSocket 消息并更新进度条
- [ ] 进度条显示百分比和渐变色动画
- [ ] 更新统计区域：成功数、失败数、耗时、剩余时间、总行数
- [ ] 批次详情表格实时更新，新增完成的批次
- [ ] 使用绿色标记成功批次，红色标记失败批次
- [ ] 显示每批次的详细信息：参数值、状态、耗时、影响行数
- [ ] 失败批次显示错误信息
- [ ] 计算并显示执行速度（批次/秒）
- [ ] 执行完成后显示"执行完成"提示
- [ ] 表格支持虚拟滚动，处理几百条数据流畅
