# Issue #4: 前端批量进度 Tab UI

## Parent

[PRD: 批量执行进度显示](../PRD.md)

## What to build

在流程设计页面的底部面板（Terminal.vue）中新增"批量进度" Tab。设计并实现批量执行进度的 UI 布局，包括：
- 整体进度条（显示百分比）
- 统计区域（成功数、失败数、已用时间、预计剩余时间、总处理行数）
- 可展开的批次详情表格（使用 Element UI 的 el-table）
- 取消按钮

表格列包括：批次序号、参数值、状态、耗时、影响行数、错误信息。表格默认折叠，点击展开查看详情。使用绿色标记成功批次，红色标记失败批次。

## Acceptance criteria

- [ ] 在 Terminal.vue 中新增"批量进度" Tab
- [ ] 实现进度条组件，显示百分比和动画效果
- [ ] 实现统计区域，显示成功/失败/耗时/行数信息
- [ ] 实现批次详情表格，支持展开/折叠
- [ ] 表格列：批次、参数值、状态、耗时、影响行数、错误信息
- [ ] 实现取消按钮（初始禁用，执行时启用）
- [ ] 使用绿色/红色标记成功/失败状态
- [ ] 进度条使用渐变色，视觉效果良好
- [ ] 批次详情表格支持虚拟滚动（处理几百条数据）
