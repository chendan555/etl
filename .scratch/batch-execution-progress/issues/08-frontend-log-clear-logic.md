# Issue #8: 前端日志清空逻辑

## Parent

[PRD: 批量执行进度显示](../PRD.md)

## What to build

实现前端日志清空逻辑，确保下次执行时自动清空旧的进度日志，保留当前执行的日志。

核心功能：
- 用户点击"执行"时清空批量进度 Tab 的所有数据
- 清空进度条、统计信息、批次详情表格
- 重置取消按钮状态
- 保留当前执行的日志直到下次执行
- 不需要手动清除按钮

## Acceptance criteria

- [ ] 点击"执行"按钮时清空批量进度 Tab 的所有数据
- [ ] 重置进度条为 0%
- [ ] 清空统计信息（成功数、失败数、耗时等）
- [ ] 清空批次详情表格
- [ ] 重置取消按钮状态（禁用）
- [ ] 重置执行状态（非 running/completed/cancelled）
- [ ] 不影响其他 Tab 的数据（步骤度量、日志）
- [ ] 编写测试验证日志清空逻辑
