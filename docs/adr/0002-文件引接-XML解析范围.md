# 0002: 文件引接 XML 解析范围

## 状态
已接受

## 背景
解析协议（YjProtocol）支持 TXT/CSV/DAT/XML 四种文件类型。当前 `execFile()` 只实现了文本分隔符解析，XML 解析完全缺失。

## 决策
第一版只支持**扁平 XML 结构**：`<record>` 节点下直接是 `<key>value</key>`，自动拍平为行和列。

## 取舍
- **优点**：覆盖大部分引接场景，实现简单
- **限制**：不支持嵌套节点、XML namespace、属性映射
- **扩展路径**：后续如需要复杂 XML，可在 `jsonForm` 中增加 XPath 映射配置

## 示例格式
```xml
<records>
  <record>
    <name>张三</name>
    <age>25</age>
  </record>
</records>
```
