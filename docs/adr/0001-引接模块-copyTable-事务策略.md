# 0001: 引接模块 copyTable 事务策略

## 状态
已接受

## 背景
`YjExecService.copyTable()` 执行数据库表引接时，先 DELETE 全表再逐批 INSERT（每 1000 行提交一次）。如果 INSERT 中途失败，DELETE 已提交无法回滚，导致数据丢失。

## 决策
采用**同事务 DELETE+INSERT**：将 DELETE 和所有 INSERT 放在同一个事务中，全成功或全回滚。

## 取舍
- **优点**：实现简单，数据一致性有保障
- **代价**：大表（几十万行）可能锁表几十秒
- **放弃的方案**：分批事务（按行范围 DELETE+INSERT），实现复杂度高，且引接场景下并发写入少，不需要

## 适用场景
引接表通常只有引接任务在写入，无高并发写入冲突。
